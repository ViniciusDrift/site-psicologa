# Site Thamiris Ribeiro — Psicóloga

Landing page estática (HTML/CSS/JS), pronta para hospedagem gratuita.

## Ver localmente

Abra `index.html` no navegador ou, nesta pasta:

```bash
python3 -m http.server 8080
```

Depois acesse http://localhost:8080

## Publicar de graça (GitHub Pages)

1. Crie um repositório no GitHub (público).
2. Envie esta pasta:

```bash
git add .
git commit -m "Site da psicóloga Thamiris Ribeiro"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/site_thamiris.git
git push -u origin main
```

3. No GitHub: **Settings → Pages → Branch: main / pasta: / (root) → Save**.
4. O site fica em `https://SEU_USUARIO.github.io/site_thamiris/`.

## Personalizar

No `index.html`, troque:
